`stayfixed memory index`, and the index `stayfixed attach` renders, carry a store's approval across
the files they write themselves, and they no longer put back an approval you withdrew, or replace
one you gave anew, while they ran: the approval moves only while the record still holds the digest
the command read before writing, and the command says it was not carried over otherwise. Carrying
it keeps the time you approved, so `stayfixed trust list --all` says when you approved and not when
the index last ran.
